## 秘密仅走本地安全配置

正式SID、appName、appkey及其他实际签名密钥只由授权人员填入本地 `.local/secrets/wdt.env`（Git忽略、权限0600）或受控密钥存储；不要发聊天、写模板、截图或提交Git。文档只记“配置引用/已配置/未配置”。由授权人员填写该私有文件，不填写已跟踪的.env模板。跨境文档公共请求字段为 `appName`、`sid`、`sign`、`timestamp`，部分请求含 `body`；签名密钥名称与签名算法须按所选产品正式文档核验，不自行替换为 clientId 或 access_token。appName在摘录中称“第三方应用key”，它与appkey的具体关系仍待正式产品核验。

容易遗漏的问题：两店即使属于同平台，也可能共享多个仓库和其他店铺库存；退款返回仅含店名时也无法据此稳定区分同名店。必须补齐稳定身份关联，否则库存重复与退款串店会导致规则错误。
